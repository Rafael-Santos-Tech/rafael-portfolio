O portfólio apresenta projetos voltados ao desenvolvimento de software, incluindo aplicações Web, análise de dados e desenvolvimento Back-end.

### 📊 1. Analisador de Dados com Python e Pandas

Aplicação de linha de comando (CLI) desenvolvida para processar e analisar dados comerciais armazenados em arquivos CSV.

**Principais funcionalidades:**

- Leitura e processamento de arquivos CSV.
- Menu interativo executado no terminal.
- Visualização de estatísticas descritivas.
- Filtragem de produtos por faixa de preço.
- Análise de desempenho comercial.
- Cálculos de métricas de faturamento.
- Exportação de informações processadas.

**Tecnologias:** Python, Pandas e CSV.

**Conhecimentos aplicados:** manipulação de DataFrames, estruturas condicionais, operações vetorizadas e processamento de dados.

🔗 **[Ver projeto no GitHub](https://github.com/Rafael-Santos-Tech/Python-mini-projetos/tree/main/analisador_de-dados)**

### 🎮 2. Infinite Play — API RESTful com Flask

API REST desenvolvida em Python utilizando Flask para gerenciar um catálogo de jogos digitais.

O projeto implementa operações CRUD e utiliza arquivos JSON para armazenamento persistente das informações.

**Principais funcionalidades:**

- Cadastro de jogos por requisições HTTP.
- Listagem completa do catálogo.
- Consulta individual por ID.
- Atualização de informações existentes.
- Exclusão de registros.
- Persistência de dados em JSON.
- Comunicação por endpoints REST.

**Endpoints disponíveis:**

| Método | Endpoint | Funcionalidade |
|---|---|---|
| GET | `/api/jogos` | Listar jogos |
| GET | `/api/jogos/{id}` | Consultar por ID |
| POST | `/api/jogos` | Cadastrar jogo |
| PUT | `/api/jogos/{id}` | Atualizar jogo |
| DELETE | `/api/jogos/{id}` | Excluir jogo |

**Tecnologias:** Python, Flask, JSON e HTTP.

**Conhecimentos aplicados:** desenvolvimento Back-end, arquitetura REST, operações CRUD e persistência de dados.

🔗 **[Ver projeto no GitHub](https://github.com/Rafael-Santos-Tech/Python-mini-projetos/tree/main/Flask_Games_API)**

Projeto voltado ao estudo da integração entre aplicações Python e planilhas do Google Sheets.

A aplicação explora possibilidades de comunicação entre sistemas, organização de informações e automação de processos envolvendo planilhas online.

**Objetivos do projeto:**

- Desenvolver conhecimentos sobre consumo de APIs.

**Tecnologias relacionadas:** Python e Google Sheets.

**Conhecimentos abordados:** integração de sistemas, comunicação com APIs e manipulação de informações.

🔗 **[Ver projeto no GitHub](https://github.com/Rafael-Santos-Tech/Python-mini-projetos/tree/main/integracao_google_sheets)**

## 💻 Como Executar Localmente

O portfólio é desenvolvido com tecnologias Web que podem ser executadas diretamente no navegador.

### 1. Pré-requisitos

- Git instalado.
- Navegador Web atualizado.
- Visual Studio Code (opcional).

### 2. Clonar o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/Rafael-Santos-Tech/rafael-portfolio.git
```

### 3. Acessar a pasta do projeto

```bash
cd rafael-portfolio
```

### 4. Executar o site

Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar as alterações durante o desenvolvimento.
